# Flagrant

Jeu d'entraînement aux drapeaux du monde : un drapeau apparaît, tu tapes son nom avant la fin du chrono.

Site statique, sans dépendance ni outil de construction : il suffit de servir le dossier tel quel (GitHub Pages, Netlify…).

## Contenu

- `index.html` : le jeu et les pages Règles, Conditions d'utilisation, Confidentialité, Mentions légales.
- `404.html` : page affichée quand un lien est cassé.
- `flags/` : 255 drapeaux en SVG, chargés un par un pendant la partie.
- `fonts/` : police Archivo (SIL Open Font License 1.1).
- `favicon.svg`, `og-image.png` : icône d'onglet et image d'aperçu lors d'un partage.
